# 食事とトレーニング

GitHub Pagesで公開する個人用ダッシュボードです。フロントエンドはこのリポジトリで管理し、本人のGoogleアカウントで認証してGoogle Sheets APIからデータを読み込みます。シート自体やGASを一般公開する必要はありません。

## 現在の構成

- `index.html`: サイトの画面
- `style.css`: モバイル対応スタイル
- `app.js`: 食事・PFC・水分・トレーニング履歴の表示
- `config.js`: Google OAuthクライアントIDとスプレッドシートID
- `Code.gs` / `Index.html`: 既存GAS版（移行中のため保持）

## Google OAuth設定（初回のみ）

1. Google Cloud Consoleでプロジェクトを作成します。
2. **Google Sheets API** を有効にします。
3. Google Auth Platformの同意画面を設定し、利用するGoogleアカウントをテストユーザーに追加します（アプリがテスト中の場合）。
4. OAuthクライアントIDを作成し、アプリケーションの種類を「ウェブアプリケーション」にします。
5. 承認済みのJavaScript生成元に `https://yh-png-cag.github.io` を登録します。
6. 発行されたOAuthクライアントIDを `config.js` の `googleClientId` に設定してコミットします。Client Secretやアクセストークンは保存しないでください。
7. サイトを開き、「Googleに接続」を押して対象のGoogleアカウントで認証します。

認証スコープは `spreadsheets.readonly` のみです。アプリはシートを書き換えません。Google認証は本人のブラウザー内で行い、シートの内容を公開リポジトリへ保存しません。

## 設定値の保存

目標カロリー、水分、PFC比率は現在のブラウザーのlocalStorageに保存します。同じブラウザーでは再読み込み後も保持されますが、別端末や別ブラウザーとは同期されません。データ記録そのものはGoogle Sheets側が正本です。

## 公開について

リポジトリのGitHub Pages設定で公開されます。OAuthクライアントIDが未設定の場合、個人データの読み込みはできません。公開サイトの画面が見えることと、スプレッドシートのデータを読めることは別です。
