# 食事ログ

Google Apps Script で Google スプレッドシート「食事管理」を読み取り、今日・直近7日・直近30日の摂取量を表示する個人用ダッシュボードです。

## ファイル
- `Code.gs`: シート読み取りと集計
- `Index.html`: モバイル向け画面

## 前提
スプレッドシートID: `1MhXIRk09s3_DQgn5JNXw5ESYzWvfxFdT3MXuQzFQ41w`
シート名: `食事管理`

1行目のヘッダーは次の名前を想定します：
`日付`, `食事区分`, `食品・メニュー`, `量・単位`, `カロリー(kcal)`, `たんぱく質P(g)`, `脂質F(g)`, `炭水化物C(g)`, `メモ`, `水分量(mL)`

## Google Apps Scriptへの配置
1. script.google.com で新しいプロジェクトを作成
2. `Code.gs` を貼り付け
3. HTMLファイルを `Index` という名前で追加し、`Index.html` を貼り付け
4. プロジェクト設定のタイムゾーンを `Asia/Tokyo` に設定
5. ウェブアプリとしてデプロイ。実行ユーザーは「自分」、アクセスできるユーザーは「自分のみ」

このアプリはシートを読み取るだけで、データの追加・変更・削除はしません。目標値は画面側のブラウザー内にのみ保存されます。GitHubへの保存とGASへのデプロイは別作業です。
